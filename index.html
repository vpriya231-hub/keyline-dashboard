                    # Direct Key execution example (instant test):

                    curl -X POST https://keyline.v0408688.workers.dev/v1/chat/completions \

                    For production apps, public GitHub repos, or Android/client-side apps, never hardcode your key directly in source files. Instead, set it as an environment variable or system secret using either of the supported keys:
                  

                  

                    

                      
Primary Gateway Variable

                      KEYLINE_API_KEY="your_api_key_here"
                    

                    

                      
Alternative Supported Alias

                      V_ASTRA_API_KEY="your_api_key_here"
                    

                  

                  

                    # In your .env file (ensure .env is included in .gitignore!):

                    KEYLINE_API_KEY="keyline_live_xxxxxxxxxxxxxxxx"

                    # Or universal engine alias:

                    V_ASTRA_API_KEY="keyline_live_xxxxxxxxxxxxxxxx"
                  

                  

                    

                      Python: os.environ.get("KEYLINE_API_KEY")
                    

                    

                      Node.js: process.env.KEYLINE_API_KEY
                    

                    

                      Android: local.properties → BuildConfig

Keyline Policies & Terms

              
Legal compliance, security, pricing transparency, and customer support documentation

            

          

          
        


        
        

          
          
          
          
        


        
        

          
1. Introduction & Acceptance

          
Welcome to Keyline AI Gateway ("Keyline", "we", "us", or "our"). By accessing, creating an account, evaluating via Reviewer Access, or routing API requests through our gateway, you agree to be bound by these Terms of Service. If you do not agree with any part of these terms, please refrain from using our services.


          
2. Gateway Services & Unified Billing

          
Keyline operates as a high-performance proxy and ledger gateway connecting developers to leading large language models (including Gemini, Qwen, DeepSeek, and OpenAI-compatible models). Access to services is governed by token balances purchased or granted in your account wallet. Exact token rates and model multipliers apply as specified in our pricing tiers.


          
3. Account & API Key Security

          
You are solely responsible for maintaining the confidentiality of your API keys and credentials. Any requests authenticated with your secret keys will be billed to your credit balance. In the event of an unauthorized compromise, you may immediately revoke or regenerate keys via the Keyline dashboard.


          
4. Acceptable Use Policy

          
You agree not to use Keyline for unlawful activities, hate speech generation, malware synthesis, unauthorized scraping, or intentional denial-of-service attacks on upstream model providers. Keyline reserves the right to suspend or terminate accounts that violate upstream acceptable use guidelines.


          
5. Service Availability & Rate Limits

          
While we target 99.9% uptime, gateway availability depends on Cloudflare edge routing and upstream provider response times. Keyline provides real-time latency monitoring and standard HTTP status codes (such as 429 for rate exhaustion or 402 for insufficient credits).

        


        
        

          
1. Information We Collect

          
We collect only the minimum required information to provide the gateway service: your authenticated identity (Google or GitHub email and display name), wallet transaction receipts, and request metadata (timestamps, token usage breakdown, model identifier, and response status codes).


          
2. Zero-Retention of Prompt & Generation Payloads

          
Keyline operates as a zero-data retention pass-through gateway. We do not store, inspect, log, or train on the actual text prompts or model completion contents processed through our API endpoints. Requests are streamed directly between your application and upstream LLM providers via encrypted HTTPS/TLS 1.3 connections.


          
3. Data Storage & Infrastructure

          
All user authentication records, wallet ledger balances, and API keys are stored in Google Cloud Firestore with enterprise-grade encryption at rest and in transit. Telemetry logs are strictly scoped to the authenticated user's private document partition.


          
4. User Rights & Account Deletion

          
You retain full ownership of your data. You may permanently delete your account, wipe all stored API keys, and purge historical telemetry records at any time using the self-service "Danger Zone" in your dashboard.

        


        
        

          
1. Wallet Credits & Payments

          
Keyline AI operates on a pre-paid credit wallet model. Payments are securely processed in Indian Rupees (INR) via Razorpay, supporting UPI, NetBanking, Debit/Credit Cards, and Wallets with instant digital settlement.


          
2. 7-Day Refund Guarantee

          
We offer a hassle-free 7-day refund policy for wallet top-ups. If you are unsatisfied with the service or made an accidental top-up, you may request a full refund within 7 calendar days of the transaction date, provided that less than 5% of the purchased credits have been consumed.


          
3. Refund Processing Timeline

          
Approved refunds are credited directly back to the original payment method (e.g., source bank account or UPI handle) via Razorpay within 5 to 7 business days. Processing fees may be deducted where mandated by banking partners.


          
4. How to Request a Refund

          
To request a refund, please send an email to billing@keyline.ai with your registered account email and Razorpay Payment ID. Our support team reviews all requests within 24 business hours.
